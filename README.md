MNIST Handwritten Digit Classification using ANN
📌 Project Overview

This project focuses on recognizing handwritten digits using an Artificial Neural Network (ANN) and the MNIST dataset.

The project demonstrates the basic deep learning workflow, including loading and exploring the dataset, preprocessing images, building neural network models, training the models, making predictions, and evaluating performance.

🎯 Objectives
Load and explore the MNIST handwritten digit dataset
Visualize handwritten digit images
Preprocess and normalize image data
Build an Artificial Neural Network
Compare neural network architectures
Train the model on handwritten digit images
Predict handwritten digits
Evaluate model performance
🛠️ Technologies Used
Python
NumPy
Matplotlib
TensorFlow
Keras
Jupyter Notebook
🔢 Dataset

The MNIST dataset contains handwritten images of digits from 0 to 9.

Each image has a resolution of:

28 × 28 pixels

The pixel values are normalized before being provided to the neural network.

🧠 Neural Network

The project demonstrates Artificial Neural Networks with different architectures, including:

Neural network without a hidden layer
Neural network with hidden layers
ReLU activation
Sigmoid activation
Flatten layer
📊 Model Evaluation

The project evaluates the neural network model using prediction results and performance metrics.

A confusion matrix is also used to analyze the classification results for the different digit classes.
